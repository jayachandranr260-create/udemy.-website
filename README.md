# Udemy Web Development Course Details Web Page

A simple web page built using HTML and basic CSS to display the details of a Udemy Web Development course.  
It presents the course information in a clean, easy-to-read layout.

## Features
- Course title and description
- Course details section
- Clean and simple design
- Easy navigation
- Built using HTML and CSS

## Pages / Sections
- Home page with course introduction
- Course details section
- Contact or enrollment information

## Technologies Used
- HTML5
- CSS3
